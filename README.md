# shrey.p

A minimal personal portfolio with a technical visual system, subtle motion, and a deliberate empty state for projects that are still in development.

## Local preview

Open `dist/index.html` directly in a browser, or serve the `dist` directory with any static web server.

## Customize

- Add your email and LinkedIn links when ready.
- The GitHub contact already points to [ShreyPa](https://github.com/ShreyPa).
- Replace the project empty state with real project cards as you build them.

## Deploy

This is a static site, so it works on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any standard web host.

For Vercel, import the GitHub repository, keep the Framework Preset set to **Other**, and deploy. The included `vercel.json` serves the `dist` folder with no build step.
